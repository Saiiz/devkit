# DevKit V1 Release Checklist

- [x] Production build validated by project owner
- [x] Vitest suite passing
- [x] Dark/light QA pass
- [x] Local-first processing for core utilities
- [x] Responsive navigation
- [x] Keyboard-accessible focus states
- [x] GitHub Pages workflow included
- [x] Security policy
- [x] Contributing guide
- [x] Open-source license

Before publishing:
1. Run `npm install`
2. Run `npm run build`
3. Run `npm test`
4. Run `npm run dev` and manually test all tools in dark and light mode
5. Push to GitHub
6. Enable GitHub Pages using GitHub Actions
