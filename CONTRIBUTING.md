# Contributing to DevKit

Thanks for contributing!

## Development

```bash
npm install
npm run dev
```

Before opening a pull request:

1. Keep changes focused.
2. Run `npm run build`.
3. Run `npm test`.
4. Update documentation when needed.

## Adding a tool

A new tool should be useful to developers, fast, accessible, and preferably work entirely client-side.

Please include a clear name, description, category, UI, and tests where appropriate.
